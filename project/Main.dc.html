MODE 1 · STAGE (DARK)

For arrival, atmosphere and decisions

Heroes, navigation, the services orbit, the process loop, review highlights, CTAs and the footer. The Core lives here. Short copy only.

MODE 2 · PAGE (CREAM)

For reading, comparing and trust

Service detail, case study stories, blog articles, pricing, review lists, FAQs and forms. Editorial column, calm motion, no glow behind text.

READABILITY RULES

  • Body: Manrope 18/1.75, max 68 characters per line
  • Unbounded for headings only, 3 lines max
  • Outline type is decorative, ≥56 px, never the only copy
  • No glow or image behind running text
  • 4.5:1 minimum contrast everywhere
  • Sticky table of contents on long pages

PERFORMANCE RULES

  • No WebGL. The Core is CSS gradients + SVG orbit
  • Background blur on the nav capsule only
  • GSAP + ScrollTrigger loaded only on pages that use them
  • Lenis on desktop only; native scroll on touch
  • Ambient loops pause off-screen and with reduced motion
  • Targets: LCP < 2.5 s, CLS < 0.1, INP < 200 ms

IDENTITY RULES

  • One Core per view: hero, or CTA, never both on screen
  • Amber = active / now; Coral = energy / links
  • Orbit arcs frame heroes and selectors only
  • Pills for actions, 28 px cards, glass edges
  • Every page: opens on Stage → reads on Page → closes on Stage
  • Page transition: the portal opens from the dot
